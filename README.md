🏦 Banking Management System

A Banking Management System built to simulate basic banking operations such as account creation, deposits, withdrawals, and balance management.
This project demonstrates core backend logic, database handling, and object-oriented programming concepts used in financial applications.

📌 Features

✨ User Account Creation – Create new bank accounts with unique account numbers
💰 Deposit Money – Add money to an account securely
💸 Withdraw Money – Withdraw funds from the account
📊 Balance Inquiry – Check current account balance
🔐 Secure Data Handling – Store user details and account information in a database

🛠️ Tech Stack

Language: Java

Database: MySQL

IDE: IntelliJ IDEA

Concepts Used:

Object Oriented Programming (OOP)

JDBC Database Connectivity

CRUD Operations
